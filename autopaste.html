Auto-paste into your SQL editor

Click ↗ on a query in Outbox and it opens the editor with the query already pasted in. A web page can't type into another site's tab on its own, so this needs a small userscript running on the editor's page. One-time setup, about a minute.

Checking…
  1. Install Tampermonkey (the userscript manager) in Chrome.
    Open Tampermonkey in the Chrome Web Store
  2. Let it run userscripts. Open chrome://extensions, find Tampermonkey → Details, and turn on Allow User Scripts (on older Chrome versions: turn on Developer mode at the top right instead).
  3. Install the auto-paste script. Tampermonkey shows the script and asks you to confirm: click Install.
    Install the auto-paste script

    It only runs on , and only talks to Outbox on this computer (127.0.0.1). If you open the editor yourself, it does nothing.

  4. Try it: back in Outbox, click ↗ on any query. The editor opens and the query appears in it, with a "Pasted … from Outbox" note at the bottom. This page then shows ✓.

If the editor ever isn't found, the query is still on your clipboard: press Cmd+V.
